# To-Do List Web App

Simple To‑Do List application built with **HTML, CSS, and JavaScript**.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Export task list to a `.txt` file

## Project Structure

```
todolist.html   -> Main HTML file
todolist.css    -> Styles
todolist.js     -> Application logic
```

## How to Use

1. Download the project.
2. Open `todolist.html` in your browser.
3. Type a task and press **Add** or **Enter**.
4. Click a task to mark it as completed.
5. Click **X** to delete a task.
6. Click **Save to .txt** to export the list.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
